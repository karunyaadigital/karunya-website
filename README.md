# Karunya Digital website

Static site for https://karunyadigital.online, generated by Python.

- `build/` — generators (`build.py`, `specs.py`, `art.py`, `audit.py`, `covers.py`) and blog posts in `build/posts/*.md`
- `site/` — the generated website that Netlify publishes

## Add a blog post
1. Write `build/posts/YYYY-MM-DD-slug.md` with front matter (title, description, date, category, minutes, keyword, cover_* fields).
2. `python3 build/covers.py --suggest <Category>` prints an unused cover combo (theme/prop/layout/doc).
3. `python3 build/covers.py` renders the new cover, then `python3 build/build.py` rebuilds the site.
4. Commit and push; Netlify deploys automatically.
