# Karunya Digital website

Static site for https://karunyadigital.online, generated by Python.

- `build/` — generators (`build.py`, `specs.py`, `art.py`, `audit.py`, `covers.py`) and blog posts in `build/posts/*.md`
- `site/` — the generated website that Netlify publishes

## Add a blog post
1. Write `build/posts/YYYY-MM-DD-slug.md` with front matter (title, description, date, category, minutes, keyword, cover_* fields).
2. `python3 build/covers.py --suggest <Category>` prints an unused cover combo (theme/prop/layout/doc).
3. `python3 build/covers.py` renders the new cover, then `python3 build/build.py` rebuilds the site.
4. Commit and push; Netlify deploys automatically.

## No prices, no offers (owner's rule, 16 Nov 2026)
This overrides any older instruction. Never mention Karunya Digital's prices, plan amounts (Starter/Growth/Authority with Rs figures), fees, discounts, sales or offers (e.g. Black Friday) in any post, front matter, cover or page. The site has no pricing section, so never link to `services.html#pricing`; link to `services.html` instead. When a post discusses cost, explain what drives cost in general, and for Karunya say only that it shares a plan and fixed monthly fee that fits the clinic's speciality and city after a short call, with the WhatsApp link https://wa.me/916386492334.
Before committing, run `grep -nE "Rs [0-9]{2},000|#pricing|Black Friday" build/posts/*.md` and fix anything it finds.
